# YundeZi — сайт-визитка Юрия Радочина

Одностраничный персональный сайт: веб-разработка, CRM и искусственный интеллект.
Тёмная тема, крупная типографика, анимации на скролле, оптимизация под телефон.

Разделы: **Профиль** (обложка, аватар, карточка данных) → **Обо мне** →
**Направления** → **Путь** → **Проект** → **Связаться**.

Фирменный стиль — графит и оранжевый, логотип-пантера. На шапке сидит
маскот — мини-тянка в SVG, по клику меняет позу: сидит → машет →
радуется → спит.

**Опубликован:** [wertop657.github.io/Project](https://wertop657.github.io/Project/)
**Домен проекта Leo-wend:** [leo-wend.ru](https://leo-wend.ru)

`canonical`, `og:url` и `sitemap.xml` указывают на адрес github.io.
При переезде на свой домен замените их на него.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Вся разметка страницы |
| `assets/css/style.css` | Стили, адаптив, тема |
| `assets/css/fonts.css` | Подключение локальных шрифтов |
| `assets/js/main.js` | Анимации и интерактив |
| `assets/fonts/` | Unbounded + Inter (woff2, латиница и кириллица) |
| `assets/img/` | Фото, фавиконка-пантера и превью для соцсетей |

Зависимостей и сборки нет — это статика. Достаточно открыть `index.html`.

## Локальный запуск

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Открывать файл напрямую через `file://` тоже можно, но шрифты и превью
корректнее отдаются через сервер.

## Анимации и интерактив

- прелоадер: пантера бежит по шкале загрузки, позиция = процент;
- обложка профиля плавно наезжает при наведении;
- имя в первом экране собирается по буквам, фамилия выезжает градиентом;
- живой фон из связанных точек на `<canvas>`, реагирует на курсор;
- появление блоков при прокрутке (`IntersectionObserver`);
- счётчики цифр, прогресс-полоса скролла, заполнение линии таймлайна;
- кастомный курсор, магнитные кнопки и 3D-наклон карточек — только на десктопе;
- бегущая строка, плавающие градиентные пятна, зерно поверх фона;
- маскот на шапке: дыхание, качание ног, моргание, подёргивание ахоге,
  четыре позы по клику с подскоком на смене;
- «влёт в фото»: при прокрутке кадр раскрывается из окошка на весь экран
  и наезжает — эффект собран на clip-path и transform, значения считает
  скролл-обработчик.

## Оптимизация под телефон

- вёрстка в одну колонку от 900px и ниже, кнопки на всю ширину от 640px;
- бургер-меню с раскрытием по кругу, блокировка скролла при открытом меню;
- меньше частиц и ниже плотность пикселей на мобильных, анимация фона
  останавливается, когда первый экран ушёл из вида или вкладка неактивна;
- тяжёлые эффекты (курсор, магниты, наклон) не включаются на тач-устройствах;
- учитываются вырезы экрана (`env(safe-area-inset-*)`).

## Доступность

- уважается системная настройка «уменьшить движение» — анимации отключаются,
  контент остаётся видимым;
- ссылка «Перейти к содержанию», видимые состояния фокуса, `aria`-атрибуты у меню;
- без JavaScript страница остаётся читаемой.

## Производительность

Шрифты самохостятся и урезаны до нужных символов: **91 КБ** вместо 612 КБ
у полных наборов. Внешних CDN нет — ничего не ломается, если Google Fonts
недоступен.

Чтобы пересобрать шрифты после правки текстов (нужен `fonttools`):
диапазоны символов заданы в комментарии к `assets/css/fonts.css`.

## Публикация

Репозиторий уже содержит workflow `.github/workflows/deploy.yml` — при пуше
в `main` сайт публикуется на GitHub Pages.

1. **Settings → Pages → Source: GitHub Actions** — уже включено.
   Важно: окружение `github-pages` пускает деплой только с ветки
   по умолчанию, поэтому её стоит переключить на `main`
   (*Settings → General → Default branch*).
2. Для своего домена: **Settings → Pages → Custom domain** → `leo-wend.ru`,
   затем в DNS добавить записи на `185.199.108-111.153` (A) и `CNAME` для `www`.
   GitHub сам создаст файл `CNAME` в репозитории.

Файл `CNAME` намеренно не добавлен: домен `leo-wend.ru` уже используется,
и привязку лучше сделать осознанно, когда будете переносить хостинг.

Сайт — обычная статика, поэтому так же разворачивается на любом хостинге,
Netlify, Vercel или Cloudflare Pages: достаточно отдать корень репозитория.
